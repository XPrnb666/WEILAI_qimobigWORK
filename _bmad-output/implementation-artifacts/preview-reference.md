```js
localStorage.setItem("quicktask.tasks", JSON.stringify(demo))
location.reload()
```

清空全部任务（得到真正的空列表，用于演示空状态）：

```js
localStorage.setItem("quicktask.tasks", "[]")
location.reload()
```

恢复示例数据（删除本地记录后刷新，页面会重新展示内置示例）：

```js
localStorage.removeItem("quicktask.tasks")
location.reload()
```

> 存储键名为 `quicktask.tasks`，与 [src/App.tsx](file:///g:/WEILAI_bybs_k617/src/App.tsx) 中的 `STORAGE_KEY` 一致。执行前请确认当前浏览器里没有需要保留的真实任务。

## 三、演示脚本（约 5 分钟）

按顺序操作，每一步都给出预期界面表现，便于旁人对照检查。

| 步骤 | 操作 | 预期表现 |
|------|------|----------|
| 1 | 打开 http://localhost:8443/（首次访问、本地无数据） | 顶部显示 QuickTask，列表直接展示 12 条内置示例，统计为 12/9/3 |
| 2 | 点击右上角“添加任务” | 弹出“添加任务”对话框，含标题、分类、截止日期三个字段 |
| 3 | 直接点击“添加任务”提交 | 三个字段下方分别出现红色错误提示，对话框不关闭 |
| 4 | 填写标题“整理本周工作计划（已修订）”、分类“工作”、日期 2026-10-23，提交 | 对话框关闭，新任务出现在列表顶部，统计变为 13/10/3 |
| 5 | 点击筛选“待完成” | 仅显示 10 条未完成任务，筛选标签高亮 |
| 6 | 点击筛选“已完成” | 仅显示 3 条已完成任务，标题带删除线、复选框为实心勾选 |
| 7 | 点击筛选“全部” | 恢复显示 13 条任务 |
| 8 | 在搜索框输入“复习” | 仅显示“复习数据结构与算法”1 条；点击搜索框右侧清除按钮后恢复 |
| 9 | 在搜索框输入“不存在的内容” | 显示空状态“没有匹配的任务”，且不显示“添加任务”按钮 |
| 10 | 点击某条任务的“更多”按钮 → “编辑任务” | 弹出“编辑任务”对话框，且标题、分类、日期已预填该任务原值 |
| 11 | 把标题改为“整理本周工作计划（已修订 v2）”，保存 | 列表标题更新，统计不变，任务位置不变 |
| 12 | 点击某条任务的“更多”按钮 → “删除任务” → “确认删除” | 任务从列表移除，统计相应减少；点“取消”则不变 |
| 13 | 按 F5 刷新页面 | 剩余任务全部保留，顺序与状态不变（数据来自 localStorage） |
| 14 | 拖动窗口宽度至 400px 左右 | 添加按钮变为右下角圆形悬浮按钮；筛选标签占满整行；分类标签在极窄屏隐藏 |
| 15 | 控制台执行 `localStorage.setItem("quicktask.tasks","[]");location.reload()`（可选） | 列表清空并显示空状态，统计 0/0/0，下方出现 6 条示例任务；点击任一条可打开新增表单并自动填入标题、分类、日期 |

## 五、边界情况参考

演示时可顺带说明以下已知行为，避免被误认为缺陷：

| 情况 | 当前行为 | 说明 |
|------|----------|------|
| 任务标题为空 | 提示“请输入任务标题”，不可提交 | 表单校验 |
| 分类为空 | 提示“请输入任务分类”，不可提交 | 表单校验 |
| 未选截止日期 | 提示“请选择截止日期”，不可提交 | 截止日期为必填 |
| 标题全为空格 | 同上，按空值处理（`trim()` 后判空） | 不会生成只含空格的任务 |
| 搜索无结果 | 显示“没有匹配的任务”空状态 | 不显示“添加任务”按钮，避免误操作 |
| 清除浏览器数据 | 任务全部丢失 | 无后端，无备份能力 |
| 两个任务同名 | 允许，按 `id` 区分 | 不影响编辑或删除 |
| 手动改过 localStorage 结构 | 非法条目被过滤，页面不崩溃 | 加载时逐条校验字段类型 |
