## 核心价值

QuickTask 解决的问题：**用最少的操作完成日常待办管理**。市面上已有大量待办应用，但多数功能较重、配置复杂。QuickTask 提供一个干净、轻量、零配置的待办体验——打开即可用，数据自动保存。

## 目标用户

- 课程作业展示的评审者 / 老师
- 个人轻度待办用户（不需要跨设备同步或高级功能）

## MVP 功能范围（已实现）

| 模块 | 功能 |
|------|------|
| 任务展示 | 标题、分类、截止日期、完成状态；已完成任务带删除线 |
| 新增任务 | 弹窗表单，含标题、分类、截止日期三个必填字段；有校验 |
| 编辑任务 | 更多菜单 → 编辑；复用新增弹窗，预填原值 |
| 完成切换 | 圆形复选框点击切换；即时视觉反馈 |
| 删除任务 | 更多菜单 → 删除；二次确认弹窗 |
| 筛选 | 全部 / 待完成 / 已完成，各带计数 |
| 搜索 | 按标题模糊匹配；含清除按钮 |
| 持久化 | 启动时从 localStorage 加载，变更时保存；刷新不丢失 |
| 空状态 | 不同筛选下的友好文案；空列表下方展示 6 条可点击示例 |
| 响应式 | 桌面端（FAB 在右上角）+ 移动端（FAB 在右下角，筛选占满一行） |
| 初始示例 | 首次打开展示 12 条内置示例任务（覆盖不同分类、不同截止日期、已/未完成） |

## 明确不做的（MVP 范围外）

- 账号体系（注册、登录、个人资料、多用户隔离）
- 后端服务或 API
- 跨设备同步
- 任务优先级系统
- 分类标签预设 / 颜色标记
- 批量操作（多选、批量完成、批量删除）
- 提醒 / 通知
- 拖拽排序
- 附件、评论、子任务
- PWA 离线安装

## 已知局限

1. **数据仅在当前浏览器当前设备**：清除浏览器数据即丢失
2. 分类为自由文本，无预设
3. 截止日期为必填项（MVP 设计选择）
4. 搜索只匹配标题
5. 无任务数量上限检查（localStorage 限额内可存数千条）

## 验收标准（摘要）

1. 页面正常显示，空状态友好
2. 新增 / 编辑 / 完成切换 / 删除 / 筛选 / 搜索六个核心功能均可独立验证
3. 刷新后数据保留
4. 窄屏（≤420px）下布局无明显问题
5. `pnpm build` 构建成功，无 TypeScript 错误
6. 控制台无运行时错误
7. 提交记录体现：需求 → 实现 → 验证的顺序
